# 📰 Fake News Detector

**Fake News Detector** is an intelligent web-based system that automatically detects and classifies news as **Real or Fake** using **Machine Learning and Natural Language Processing (NLP)** techniques.

The main goal of this project is to help identify misleading or false information and reduce the spread of misinformation.
